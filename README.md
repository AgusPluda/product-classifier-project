## Dataset

The dataset contains demographic and health-related information for insurance beneficiaries.

| Variable   | Description                                                   |
| ---------- | ------------------------------------------------------------- |
| `age`      | Age of the beneficiary                                        |
| `sex`      | Gender                                                        |
| `bmi`      | Body Mass Index                                               |
| `children` | Number of dependents covered by insurance                     |
| `smoker`   | Smoking status                                                |
| `region`   | Residential region in the United States                       |
| `charges`  | Individual medical insurance costs billed by health insurance |
